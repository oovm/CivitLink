# My First STG

这是一个使用 GG 游戏引擎创建的射击游戏示例。

## 项目结构

```
my-first-stg/
├── assets/           # 资源目录
│   ├── audio/        # 音频资源
│   │   ├── bgm/      # 背景音乐
│   │   └── sfx/      # 音效
│   ├── graphics/     # 图形资源
│   │   ├── sprites/  # 精灵
│   │   ├── backgrounds/ # 背景
│   │   └── ui/       # UI 资源
│   ├── prefabs/      # 预制体
│   ├── scripts/      # 脚本文件
│   └── scenes/       # 场景配置
├── config/           # 配置文件
├── README.md         # 项目说明
└── game.toml         # 引擎配置
```

## 核心功能

- **飞船控制**：支持上下左右移动和射击
- **敌人系统**：多种类型的敌人，不同的属性和行为
- **子弹系统**：玩家子弹和敌人子弹
- **碰撞检测**：检测飞船与敌人、子弹的碰撞
- **计分系统**：消灭敌人获得分数
- **波次系统**：随着波次增加，敌人数量和种类会变化
- **特殊攻击**：支持散弹攻击
- **音效系统**：射击、爆炸、受伤等音效

## 如何运行

1. 确保你已经安装了 GG 引擎
2. 进入项目目录
3. 运行 `gg run` 命令启动游戏

## 游戏玩法

- **方向键**：控制飞船移动
- **空格键**：发射子弹
- **Shift 键**：使用特殊攻击（散弹）
- **R 键**：游戏结束后重新开始

## 扩展指南

### 添加新敌人类型

1. 在 `assets/scripts/start.valkyrie` 文件中，找到 `enemy_configs` 数组
2. 添加新的敌人配置对象，包含 type、width、height、speed、health、fire_rate、bullet_speed、score 等属性
3. 敌人会自动在游戏中生成

### 添加新子弹类型

1. 在 `fire_bullet` 函数中，添加新的子弹逻辑
2. 可以修改子弹的速度、大小、外观等属性

### 添加新波次配置

1. 在 `spawn_enemies` 函数中，修改 `enemies_per_wave` 的计算逻辑
2. 可以根据波次调整敌人的生成频率和数量

## 技术说明

- **Valkyrie 脚本**：使用内置脚本系统实现游戏逻辑
- **实体系统**：使用 GG 引擎的实体系统创建游戏对象
- **碰撞系统**：使用 GG 引擎的碰撞检测系统
- **音频系统**：使用 GG 引擎的音频系统播放音效和背景音乐
- **渲染系统**：使用 GG 引擎的渲染系统显示游戏元素

## 注意事项

- 本示例使用占位资源，实际开发中需要替换为真实资源
- 本示例只实现了基础功能，实际游戏可能需要更多功能扩展
