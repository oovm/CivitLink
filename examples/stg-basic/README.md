# STG 引擎基本示例

这是一个使用 GG STG 引擎创建的基本射击游戏示例，展示了 STG 引擎的核心功能。

## 功能特性

- 玩家控制：使用方向键移动玩家角色
- 射击系统：使用空格键发射子弹
- 敌人 AI：敌人会自动移动和攻击
- 碰撞检测：检测玩家与敌人、子弹与敌人的碰撞
- 生命值系统：玩家和敌人都有生命值

## 运行方法

1. 确保你已经安装了 Rust 和 Cargo
2. 在项目根目录运行以下命令：

```bash
cargo run --example stg-basic
```

## 控制说明

- **方向键**：移动玩家角色
- **空格键**：射击
- **Shift**：特殊武器

## 游戏玩法

1. 控制玩家角色移动，避开敌人的攻击
2. 射击敌人，消灭所有敌人
3. 尽可能存活更长时间，获得更高分数

## 技术说明

- 使用 GG 元引擎的 ECS 系统管理游戏实体
- 使用 WGPU 进行图形渲染
- 使用 winit 处理窗口和输入事件
- 遵循 GG 元引擎的插件化架构设计
