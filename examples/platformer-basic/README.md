# Platformer 引擎基本示例

这是一个使用 GG Platformer 引擎创建的基本平台跳跃游戏示例，展示了 Platformer 引擎的核心功能。

## 功能特性

- 玩家控制：使用方向键左右移动玩家角色
- 跳跃系统：使用空格键跳跃
- 物理系统：实现了重力、碰撞检测等物理效果
- 平台系统：包含地面和空中平台
- 收集系统：可以收集金币等物品

## 运行方法

1. 确保你已经安装了 Rust 和 Cargo
2. 在项目根目录运行以下命令：

```bash
cargo run --example platformer-basic
```

## 控制说明

- **方向键左/右**：移动玩家角色
- **空格键**：跳跃

## 游戏玩法

1. 控制玩家角色移动，跳跃到不同的平台上
2. 收集金币等物品
3. 尝试到达更高的平台，探索游戏世界

## 技术说明

- 使用 GG 元引擎的 ECS 系统管理游戏实体
- 使用 WGPU 进行图形渲染
- 使用 winit 处理窗口和输入事件
- 实现了基本的物理系统，包括重力、碰撞检测等
- 遵循 GG 元引擎的插件化架构设计
