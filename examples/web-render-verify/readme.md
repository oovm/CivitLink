# Web Render Verify Example

This example demonstrates how to use the GG Game Engine's web rendering capabilities.

## Features
- Web rendering verification
- Basic rendering setup
- Cross-platform compatibility

## Usage
1. Run `cargo run --example web-render-verify`
2. Open the generated HTML file in a web browser

## Requirements
- Rust 1.60+
- wasm32-unknown-unknown target
- wasm-bindgen
