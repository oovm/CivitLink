# GG STG 引擎

GG STG 引擎是基于 GG 元引擎框架构建的射击游戏引擎，专注于 2D 射击游戏（Shoot 'em up）的开发。

## 功能特性

- **ECS 架构**：使用实体组件系统管理游戏实体
- **输入系统**：支持键盘、鼠标和游戏手柄输入
- **敌人 AI**：实现了基本的敌人 AI 行为，包括巡逻、追踪、攻击等
- **碰撞检测**：支持圆形和矩形碰撞体的碰撞检测
- **武器系统**：支持多种武器类型和射击模式
- **渲染系统**：使用 WGPU 进行图形渲染
- **资源管理**：支持图像、音频等资源的加载和管理

## 架构设计

STG 引擎采用以下架构：

1. **核心层**：基于 GG 元引擎的 ECS 核心、资源系统、渲染系统等
2. **引擎层**：STG 专用的组件、系统和插件
3. **游戏层**：具体的游戏内容和逻辑

## 核心组件

### 实体组件

- **Transform**：位置和旋转信息
- **Velocity**：速度和加速度信息
- **Sprite**：精灵渲染信息
- **Collider**：碰撞检测信息
- **Health**：生命值信息
- **Player**：玩家控制标记
- **Enemy**：敌人标记
- **Bullet**：子弹标记
- **Weapon**：武器系统
- **AI**：敌人 AI 信息

### 系统

- **InputSystem**：处理玩家输入
- **MovementSystem**：处理实体移动
- **CollisionSystem**：处理碰撞检测和响应
- **WeaponSystem**：处理武器和射击逻辑
- **AISystem**：处理敌人 AI 行为
- **RenderSystem**：处理渲染逻辑

## 使用方法

### 创建 STG 引擎实例

```rust
use gg_engine_stg::engine::StgEngine;
use gg_engine_stg::config::StgConfig;

// 创建游戏配置
let config = StgConfig::default();

// 创建 STG 引擎实例
let mut engine = StgEngine::new(config, false);

// 初始化引擎
engine.initialize()?;

// 运行游戏
engine.run()?;
```

### 配置选项

STG 引擎支持以下配置选项：

- **游戏配置**：游戏名称、版本、作者等
- **显示配置**：窗口宽度、高度、是否全屏等
- **输入配置**：移动速度、射击键、特殊武器键等
- **游戏设置**：玩家初始生命值、敌人生成间隔、子弹速度、敌人速度等

### 扩展功能

STG 引擎支持通过插件机制扩展功能：

- **自定义组件**：添加新的实体组件
- **自定义系统**：添加新的游戏系统
- **自定义插件**：添加新的功能插件

## 示例游戏

STG 引擎提供了一个基本示例游戏，展示了引擎的核心功能：

```bash
cargo run --example stg-basic
```
