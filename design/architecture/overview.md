# 架构概览

本项目是一个元游戏引擎框架，定位为编译时框架，通过插件组合机制生成具体的游戏引擎，支持多平台分发。

## 元引擎作为编译时框架的总体架构

元引擎框架采用静态与动态分离的设计思想，分为三个层次：

```
┌──────────────────────────────────────────────────────────┐
│                    元引擎框架 (编译时)                      │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐           │
│  │ ECS核心    │ │ 资源系统    │ │ 虚拟机(gwg) │           │
│  └────────────┘ └────────────┘ └────────────┘           │
│  ┌────────────────────────────────────────────────────┐ │
│  │                 插件注册与组合机制                    │ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
                              │
          (资深玩家选择插件，编译生成具体引擎)
                              ▼
┌──────────────────────────────────────────────────────────┐
│                   具体游戏引擎 (静态可执行文件)              │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐        │
│  │ Galgame插件 │ │ STG插件      │ │ 基础UI插件   │ ...    │
│  │ (静态链接)   │ │ (静态链接)   │ │ (静态链接)   │        │
│  └─────────────┘ └─────────────┘ └─────────────┘        │
│        内置编辑器（可选） + 运行时（ECS调度器）              │
└──────────────────────────────────────────────────────────┘
                              │
          (普通/高级玩家创作内容，动态加载)
                              ▼
┌──────────────────────────────────────────────────────────┐
│                      游戏实例 (运行时)                      │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 游戏项目（由DLC/Mod构成）                            │ │
│  │  ├─ 引擎配置文件（如 screen_size, default_font）    │ │
│  │  ├─ 资源包（图片、音频、剧本文件等）                  │ │
│  │  ├─ DLC内容（额外章节、角色数据）                    │ │
│  │  └─ Mod脚本（gwg代码，可注册系统/修改组件）           │ │
│  └────────────────────────────────────────────────────┘ │
│                    HMR补丁（实时更新）                     │
└──────────────────────────────────────────────────────────┘
```

### 运行时与多平台分发架构

在已有静态编译框架基础上，增加平台抽象层和构建/分发策略，确保引擎能适配 Windows、macOS、iOS、Android、H5、微信小游戏等主要平台：

```
┌──────────────────────────────────────────────────────────────┐
│                      元引擎框架 (编译时)                         │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐ │
│  │ ECS核心    │ │ 资源系统    │ │ 虚拟机(gwg) │ │ 平台抽象层  │ │
│  └────────────┘ └────────────┘ └────────────┘ └────────────┘ │
│  ┌──────────────────────────────────────────────────────────┐ │
│  │              插件组合与构建工具链 (多目标支持)               │ │
│  └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
                              │
         (针对目标平台静态链接插件，生成引擎可执行文件)
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                   具体游戏引擎 (多平台构建)                      │
├──────────────┬───────────────┬───────────────┬──────────────┤
│ Windows引擎  │ macOS引擎      │ iOS引擎       │ Android引擎  │
│ (exe)        │ (app/dmg)      │ (ipa)         │ (apk/aab)    │
├──────────────┼───────────────┼───────────────┼──────────────┤
│ H5引擎       │ 微信小游戏引擎  │ ...           │              │
│ (WASM+HTML)  │ (WASM+小游戏适配)│               │              │
└──────────────┴───────────────┴───────────────┴──────────────┘
                              │
          (游戏数据包 + DLC/Mod 跨平台分发)
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                       游戏实例 (运行时)                         │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ 游戏数据包（剧本、资源、配置）                          │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │ DLC内容（增量数据）                                    │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │ Mod脚本（gwg代码，需虚拟机执行）                       │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌────────────────────────────────────────────────────────┐ │
│  │                HMR开发支持（可选，平台限定）              │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

## Monorepo 代码组织结构

## 模块依赖关系图

```
core
├── ecs
├── asset
└── reflection
    ↓
platform (各抽象层)
    ↓
runtime (整合平台与核心)
    ↓
modules (功能模块，相互可组合)
    ├── rendering
    ├── physics
    ├── audio
    ├── ui
    └── ...
    ↓
engine (插件框架，整合模块)
    ↓
editor (编辑器框架，依赖engine和modules)
```

## 设计原则

### 1. ECS作为统一核心

借鉴Unity的DOTS架构，所有游戏逻辑最终都通过ECS系统执行，确保性能和数据驱动。ECS世界提供统一的实体、组件、系统模型，所有插件和Mod都基于此模型交互。

### 2. WASM作为脚本虚拟机

类似于Godot的GDExtension，但更安全、跨平台。脚本在沙箱中运行，不能直接访问内存。通过导入函数暴露ECS API，确保安全可控。

### 3. 插件化架构

参考Unreal的模块系统，每个功能模块独立编译，引擎构建时静态链接，保证运行时性能。插件之间通过ECS世界通信，实现松耦合。

### 4. 平台抽象层

借鉴Godot的跨平台设计，通过trait抽象各平台差异，上层代码无需关心底层实现。平台抽象层包含文件系统、输入、渲染、音频、时间与线程等子模块。

### 5. 两层monorepo结构

避免目录过深，同时保持模块清晰。`crates/`下按功能领域划分，每个领域内部再按具体模块细分。
